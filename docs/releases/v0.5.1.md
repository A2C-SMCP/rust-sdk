## v0.5.1 升级提示（旧版本卸载遗留）

如果你在 **0.5.1 之前的版本（0.3.1–0.5.0）** 上卸载过 marketplace 中的「相对 source」插件，升级后
直接重装可能报 `plugin root not found after source resolution`（`marketplace refresh` 无法自愈）。

执行恢复前，先在 marketplace 仓库中确认该插件路径确实存在（上游 manifest 失真也会报同一错误，那种
情况需要修 manifest，不要 remove）。确认是旧版卸载遗留后：

1. `marketplace info <name>` 记下源 URL（`remove` 后即查不到；含 token 的 URL 请从自己的记录取）。
2. `marketplace remove <name>` —— **默认级联卸载该 marketplace 下已安装插件并撤销 trust**；
   **不要用 `--keep-plugins`**（只跳过级联，仍删 clone 并撤销 trust，留下孤儿账本记录）。
3. `marketplace add <git-url> --trust` —— 重新 clone 并重新授予 trust。
4. `plugin install <plugin>@<name>`，此前启用过的再 `plugin enable <plugin>@<name>`。

详见 [旧版本 → 0.5.1 升级迁移](https://github.com/A2C-SMCP/rust-sdk/blob/v0.5.1/docs/computer/marketplace-0.5.1-migration.md)。
