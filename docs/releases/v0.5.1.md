## v0.5.1 升级提示（0.5.0 卸载遗留）

如果你在 0.5.0 上卸载过 marketplace 中的「相对 source」插件，升级后直接重装可能报
`plugin root not found after source resolution`（`marketplace refresh` 无法自愈）。

恢复步骤：

1. `marketplace remove <name>` —— **默认级联卸载该 marketplace 下已安装插件并撤销 trust**；
   **不要用 `--keep-plugins`**（只跳过级联，仍删 clone 并撤销 trust，留下孤儿账本记录）。
2. `marketplace add <git-url> --trust` —— 重新 clone 并重新授予 trust。
3. `plugin install <plugin>@<name>`，此前启用过的再 `plugin enable <plugin>@<name>`。

详见 [0.5.0 → 0.5.1 升级迁移](https://github.com/A2C-SMCP/rust-sdk/blob/v0.5.1/docs/computer/marketplace-0.5.1-migration.md)。
